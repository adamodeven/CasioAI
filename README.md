# CasioAI

Custom smartwatch module for a Casio A158WE — see [`GOALS.md`](GOALS.md) for
the full build spec and phased plan.

- **Phone app** (Phase 1): [`ios/`](ios/) — SwiftUI/iOS 26 app, source-complete,
  see [`ios/README.md`](ios/README.md) to build.
- **Hardware feasibility** (Phase 1.5): [`hardware/FEASIBILITY.md`](hardware/FEASIBILITY.md) —
  MCU/component selection, done ahead of firmware.
- **Watch firmware** (Phase 2, in progress): [`firmware/`](firmware/) —
  nRF Connect SDK / Zephyr, source-complete, see [`firmware/README.md`](firmware/README.md)
  to build.
- **Rev1 PCB** (Phase 3): not started.
